# Sky Island - Minecraft 3D

Одностраничный 3D сайт с летающим островом в стиле Minecraft. Весь код в одном файле `index.html`, без сборки.

## Запуск

- Открыть `index.html` в браузере (нужен интернет для загрузки Three.js с CDN).
- Или включить GitHub Pages для ветки `main`.

## Графика

- Three.js r165, WebGL2
- Процедурные пиксельные текстуры 16x16 (трава, земля, камень, руды, бревна, листва, вода, стекло, светокамень)
- Воксельный меш с отсечением скрытых граней и сглаженным ambient occlusion по вершинам
- PBR материалы, окружение из неба (PMREM)
- Мягкие тени 4096x4096, тени от облаков
- Пост-обработка: GTAO, Bloom, MSAA x4, ACES tone mapping
- Физическое небо, цикл дня и ночи, солнце и луна в стиле Minecraft, звезды
- Пруд, ручей и водопад с брызгами, анимация листвы и травы от ветра
- Дом, фонари со светом ночью, светлячки, маленькие соседние острова, два слоя облаков

## Управление

- Мышь: вращение, колесо: зум, ПКМ: сдвиг
- Клик: сломать блок, Shift + клик: поставить блок
- 1-9: выбор блока, B: режим, R: вращение, N: новый остров
